8. SESIUNI WTS, PROCESE UTILIZATOR SI COLECTAREA PROXY

FUN_140086B60 @ 0x140086B60, asociata prin calea de build cu
networkProxyCollector.cpp:

- enumera sesiunile Windows prin WTSEnumerateSessionsW;
- interogheaza informatii despre sesiune prin WTSQuerySessionInformationW;
- obtine tokenul utilizatorului prin WTSQueryUserToken;
- construieste pipe-uri anonime cu CreatePipe;
- configureaza mostenirea handle-urilor prin SetHandleInformation;
- porneste un proces in contextul utilizatorului prin CreateProcessAsUserW;
- asteapta procesul si citeste rezultatul prin ReadFile;
- interpreteaza rezultatul ca JSON prin QJsonDocument::fromJson;
- extrage campurile "uid" si "proxies";
- mentine rezultatele intr-o colectie asociata sesiunilor/utilizatorilor.

Acest traseu demonstreaza ca tlshost ruleaza ca orchestrator de serviciu si
lanseaza un helper/proces in sesiunile utilizator pentru a colecta configuratia
de proxy. Pseudocodul nu justifica inventarea unui nume suplimentar pentru
helper; raportul pastreaza concluzia la nivelul confirmat de apeluri.

13. CONCLUZIE

tlshost.exe este o aplicatie C++ x64 compilata cu Microsoft Visual C++ si
bazata pe Qt 5.6.2. Executabilul reprezinta serviciul/orchestratorul principal
al familiei Kickidler/Telemetry Service Host.

Capabilitatile confirmate static sunt:

- executie ca serviciu Windows prin QtService;
- configurare SCM si dependenta de TermService;
- pornire, oprire, suspendare, reluare si restart;
- enumerare sesiuni WTS si pornire de procese cu tokenul utilizatorului;
- IPC prin pipe si parsare JSON pentru configuratia proxy;
- initializare si coordonare manageri/collector;
- procesare, secventiere si rutare de cadre video;
- transport criptat SSL/TLS si verificare de certificate;
- protocoale de node, billing, telemetry si crash reporting.

Analiza este statica. Ea confirma existenta si traseele codului, dar nu poate
demonstra singura configuratia activa intr-o instalare, destinatiile reale de
retea sau toate efectele runtime.
