ANALIZA STATICA GHIDRA MCP - tlssubservice.exe / grabberSubAgent
Data: 2026-09-21

1. IDENTIFICAREA PROGRAMULUI

Analiza a fost efectuata asupra programului activ din Ghidra MCP.

Binarul nu contine literalul "tlssubservice.exe". Identitatea interna este
sustinuta direct de:
- 0x1400DBE50:
  R:\bbuild-7\KICK-EVPROD-WIN64\components\app-grabberSubAgent\main.cpp
- 0x1400DBEE0: "KickidlerGrabber"
- 0x1400DBF40: "-ipc-name"
- namespace-urile si clasele grabberSubAgent::*;
- modulele impl-grabberSubAgent-io, -userInfo, -http si -ui.

Concluzia prudenta este ca programul analizat este grabberSubAgent, distribuit
extern sub numele tlssubservice.exe. Maparea externa a acestui nume este
observata in celelalte componente ale suitei, nu ca literal in acest binar.

3. PORNIREA APLICATIEI

- entry @ 0x140002F04 initializeaza security cookie-ul.
- Startup-ul CRT este FUN_1400B85A0.
- FUN_1400170F0(int, char **) este functia main, identificata prin referinta
  la "KickidlerGrabber", main.cpp si argumentele specifice.
- Aplicatia construieste QApplication si dezactiveaza inchiderea automata la
  disparitia ultimei ferestre.
- SetProcessShutdownParameters este apelat, iar ProcessIdToSessionId obtine
  sesiunea curenta.
- Logurile sunt separate pe sesiune si pot primi "-logging-postfix".
- Event loop-ul este QApplication::exec().

4. MODURI DE EXECUTIE SI ARGUMENTE

Argumente observate direct:
- "-get-network-proxies": mod one-shot care colecteaza proxy-urile sistemului,
  produce rezultatul si termina fara a porni UI-ul principal;
- "-logging-postfix": postfix pentru fisierele de log;
- "-ipc-name": numele obligatoriu al canalului local catre grabberAgent.

Daca "-ipc-name" lipseste, programul logheaza "IPC name not specified" si
returneaza eroare. Cand argumentul este valid, logheaza "start agent for <sid>",
construieste serviciul IPC si intra in event loop.

5. SERVICIUL IPC

Componenta impl-grabberSubAgent-io::Service este nucleul procesului:
- deschide canalul local identificat de "-ipc-name";
- conecteaza cererile venite de la grabberAgent la serviciile subagentului;
- retransmite raspunsurile si evenimentele catre procesul parinte;
- trateaza deconectarea, reconnect-ul si shutdown-ul;
- leaga user-info, clipboard, HTTP si managerii UI.

Stringurile Qt meta-object arata sloturi pentru getUserInfo, clipboard,
notificari, Self Control si schimbarea task-urilor. Codul foloseste conexiuni
signal/slot pentru a mentine interfetele decuplate.

7. CLIPBOARD

Componenta grabberAgent::slave::slave::Clipboard este reutilizata in subagent,

Operatii expuse:

Evenimente returnate:

Sunt folosite QClipboard, QMimeData, QImage si modurile Clipboard/Selection/

direct din serviciul privilegiat.

8. PROXY SI RETEA

Modul "-get-network-proxies" foloseste QNetworkProxyFactory si
systemProxyForQuery. Sunt reprezentate tipurile NoProxy, DefaultProxy, SOCKS5,
HTTP si proxy-uri de cache. Setarile pot include host, port, user, parola si
reguli bypass. Proxy-urile rezultate sunt serializate pentru procesul parinte.

9. LOCAL RPC

Clasa localrpc::Caller gestioneaza apelurile locale asincrone si corelarea
cererilor cu raspunsurile. Stringul "unknown localrpc connection" indica
validarea identitatii conexiunii. Canalul este folosit intre serviciul IPC si
managerii subagentului pentru operatii care necesita raspuns.

Trei rutine principale local RPC au depasit timeout-ul de 5 secunde al
decompilatorului MCP. Pentru a nu lasa erori brute in fisier, au fost incluse
functii helper valide din aceleasi zone de cod. Limitarea nu schimba
identificarea modulului, sustinuta de stringuri, xref-uri si tipul RTTI
localrpc::Caller.

10. HTTP SI WEB TOKEN

grabberSubAgent::http::Manager foloseste QNetworkAccessManager si poate trimite:
- HTTP GET;
- HTTP POST cu obiecte JSON;
- cereri pentru tokenul Self Control.

Mesaje observate:
- "subAgent send http GET";
- "subAgent send http POST";
- "http connected";
- "web token acquired";
- "web token is empty await some".

Tokenul este inserat in URL-ul Self Control prin parametrul "web_token".
Managerul asteapta asincron tokenul atunci cand acesta nu este inca disponibil.

14. SCREEN TRACKING SI GUI

gui-base::ScreenTracker si gui-utils::ScreenInformer urmaresc ecranul pe care
trebuie pozitionate ferestrele QML. QGuiApplication::screens si semnalele de
schimbare a ecranului permit mutarea corecta a notificarii sau panoului atunci
cand topologia monitoarelor se schimba.

Initializer-ul GUI incarca traducerile, resursele QML, providerii de imagini si
context properties. Sunt prezente URL-uri Kickidler pentru documentatie si
istoricul versiunilor, cu variante de limba/domeniu.

15. FISIERUL C++ DECOMPILAT

Fisierul tlssubservice.cpp contine 45 de blocuri de pseudocod, aproximativ
526 KB si 11.903 linii, grupate in:
- startup si moduri;
- serviciu IPC;
- informatii utilizator/ADSI;
- clipboard si local RPC;
- HTTP si web token;
- UI si settings;
- notificari si Self Control;
- resurse GUI si screen tracking.

Verificarea finala urmareste eliminarea raspunsurilor MCP brute, a
traceback-urilor si a adreselor invalide. Functiile incluse pastreaza adresele,
numele FUN_/DAT_/LAB_, tipurile incomplete si avertismentele Ghidra.

Limitari:
- pseudocodul nu este codul-sursa original si nu este garantat compilabil;
- binarul are 7.953 functii, inclusiv Qt, CRT, STL, QML si cod generat;
- numele locale, comentariile, macro-urile si impartirea originala pe fisiere
  nu pot fi recuperate integral;
- trei functii local RPC foarte mari nu au trecut timeout-ul intern MCP, fiind
  inlocuite in selectie cu rutine helper valide, fara a fabrica implementari.

16. CONCLUZIE

tlssubservice/grabberSubAgent este procesul auxiliar interactiv al suitei.
Primeste comenzi prin IPC de la grabberAgent si executa operatii care necesita
contextul utilizatorului: informatii AD/token, clipboard, HTTP si interfete
QML. Managerii pentru notificari, Self Control si Task Tracker sunt alimentati
prin signal/slot, iar resursele GUI sunt incarcate din RCC. Separarea acestui
proces limiteaza responsabilitatile serviciului principal si izoleaza UI-ul,
clipboard-ul si cererile web in sesiunea utilizatorului.
