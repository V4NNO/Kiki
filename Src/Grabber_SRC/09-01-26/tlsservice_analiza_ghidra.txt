1. IDENTIFICAREA PROGRAMULUI ANALIZAT

Analiza a fost efectuata asupra programului activ din Ghidra MCP.
Identitatea lui este sustinuta de stringurile si codul observate in baza
Ghidra:

- 0x14026EA88: "tlsservice.exe"
- 0x14026EAC8: "tlsservice"
- 0x14026EAF0: "Telemetry Service Host"
- 0x14026EBB0: "KickidlerGrabber"
- cale de build:
  R:\bbuild-8\KICK-EVPROD-WIN64\components\app-grabberAgent\main.cpp

Fisierul tlsservice.exe nu este prezent ca fisier normal in arborele local al
workspace-ului, deci nu au putut fi calculate local hash-ul, dimensiunea sau
semnatura Authenticode. Concluziile de mai jos provin din programul deja
incarcat si analizat in Ghidra.

2. FORMAT SI LIMBAJ

- Executabil PE pe 64 de biti (image base 0x140000000).
- Limbaj principal: C++.
- Toolchain: Microsoft Visual C++ / runtime din generatia v14; sunt prezente
  VCRUNTIME140.DLL, initializarea __security_init_cookie, RTTI si nume/template
  C++ de tip std::, QSharedPointer, MessageImplHelper si clase cu namespace.
- Framework: Qt 5.6.2. Versiunea este vizibila in caile de build, iar importurile
  includ QT5CORE.DLL si QT5NETWORK.DLL, QString, QApplication, QSettings,
  QSslSocket etc.
- Exista si cod C de biblioteca integrat (de exemplu PortAudio), dar aplicatia
  si logica principala sunt C++.

Concluzie privind cerinta de limbaj: extensia .cpp este corecta. Fisierul
tlsservice_ghidra_decompiled.cpp contine pseudocodul C/C++ emis de Ghidra,
nemodificat semantic si fara functii inventate.

4. PORNIREA APLICATIEI

- entry @ 0x14000D32D initializeaza security cookie-ul si transfera controlul
  catre FUN_1401900A0, codul de startup CRT.
- FUN_140030AE0 @ 0x140030AE0 are semnatura decompilata
  int FUN_140030ae0(int param_1, char **param_2) si este functia principala a
  aplicatiei identificata si prin calea app-grabberAgent\main.cpp.
- Functia seteaza numele aplicatiei "KickidlerGrabber", proceseaza optiunea
  "-logging-postfix", construieste QApplication, citeste /grabber.ini si cheia
  misc/stealthMode, initializeaza subAgentIo si communicator, apoi intra in
  QApplication::exec().
- Mesajele observate includ "start agent",
  "This build using brand new subAgentIo system!" si
  "communicator initialization failed".

5. MAPAREA PROFILULUI tlsservice

FUN_14002EC90 @ 0x14002EC90 compara numele executabilului si construieste un
set de cinci denumiri. Pentru familia TLS observata in cod, valorile sunt:

- host/executabil: tlshost
- serviciu: tlsservice
- subserviciu: tlssubservice
- prefix/familie: tls
- descriere: Telemetry Service Host

Aceeasi functie contine profilurile grabber/ngs si nume care imita procese
Windows (svchost, WmiPrvSE, RuntimeBroker). Aceasta este o observatie statica
despre maparea numelor; singura nu demonstreaza intentie rau-intentionata.

7. DESKTOP INTERACTIV SI ENUMERAREA PROGRAMELOR

FUN_140047D80 @ 0x140047D80:

- obtine desktopul thread-ului cu GetThreadDesktop;
- deschide desktopul activ cu OpenInputDesktop;
- foloseste GetUserObjectInformation pentru numele desktopului;
- trateaza explicit stringurile "Winlogon" si "Screen-saver";
- schimba temporar desktopul cu SetThreadDesktop;
- citeste fereastra activa cu GetForegroundWindow;
- restaureaza desktopul anterior si semnalizeaza QWaitCondition.

Acest cod arata ca agentul incearca sa urmareasca sesiunea/desktopul interactiv,
inclusiv tranzitiile catre desktopul Winlogon sau screen saver.

8. CAPTURA ECRANULUI/FERESTREI

FUN_1400515A0 @ 0x1400515A0:

- compara HWND-ul cerut cu GetForegroundWindow;

FUN_1400501D0 @ 0x1400501D0:

- creeaza bitmap si DC compatibile;

9. RETEA, TRANSPORT SI TLS/SSL

Importurile si clasele arata folosirea Qt Network si a componentelor proprii:
QSslSocket, QSslCertificate, QSslConfiguration, QTcpSocket, QLocalSocket,
transport::Session, PeerVerifier si protocoale de control. Stringurile includ:

- "TLS FAIL [peer-closed]"
- "TLS OK [late-after-timeout]"
- ":/ssl/crt/tlsca.crt"
- "tlsca.crt"

Acestea sustin existenta unui canal de transport criptat si a verificarii de
certificate. Numele executabilului "tlsservice" este mapat explicit la
"Telemetry Service Host"; el nu trebuie interpretat automat doar ca abreviere
pentru protocolul TLS.

10. CALLBACK-URI TLS ALE LOADERULUI

Aceste callback-uri apartin mecanismului Thread Local Storage al PE si sunt
distincte de TLS-ul criptografic:

- tls_callback_0 @ 0x140011257 executa o lista de initializatori la
  DLL_THREAD_ATTACH (param_2 == 2), cu verificare CFG.
- __dyn_tls_init @ 0x140220B24 initializeaza/desfiinteaza obiectele thread-local.
- tls_callback_1 @ 0x140220B9C ruleaza destructorii thread-local la
  DLL_THREAD_DETACH sau DLL_PROCESS_DETACH.

11. CONCLUZIE

Programul activ este o aplicatie C++ x64, compilata cu Microsoft Visual C++ si
bazata pe Qt 5.6.2. Este componenta Kickidler/Grabber profilata, cand numele
executabilului este tlsservice.exe, ca "Telemetry Service Host".

Capabilitatile confirmate static in functiile decompilate sunt:

- hook global low-level pentru tastatura si mouse;
- urmarire WinEvent, focus, HWND, PID si titlu de fereastra;
- schimbare temporara pe desktopul interactiv;
- enumerare de programe/ferestre;
- captura GDI prin BitBlt, PrintWindow si GetDIBits;
- configurare Qt, event loop, IPC/subAgentIo si communicator;
- transport de retea cu suport SSL/TLS si verificare de certificate.

Analiza este statica. Ea confirma existenta si traseele codului, dar nu poate
demonstra singura ce optiuni sunt activate intr-o instalare concreta, ce date
sunt efectiv transmise sau comportamentul exact in toate conditiile runtime.
